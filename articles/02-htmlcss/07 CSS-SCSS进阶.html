一、伪类选择器 ​

1.1 为啥需要伪类选择器 ​

伪类选择器在CSS中的存在有着重要的意义和作用。它们提供了一种方式来选择HTML文档中无法通过简单选择器（如元素选择器、类选择器或ID选择器）直接选择的元素。伪类选择器的设计初衷和主要用途包括以下几点：

1、表达元素的特定状态 ​

伪类选择器允许开发者根据用户与页面的交互来改变元素的样式，而不需要改变HTML代码。例如，:hover伪类可以用来改变鼠标悬停在链接或按钮上时的样式，:focus伪类用于当元素获得焦点时（比如输入框被点击时），而:active伪类则用于元素被激活（通常是被点击）的瞬间。这些都是基于用户行为的动态变化，通过CSS直接实现，无需JavaScript介入，提高了网页的交互性和用户体验。

vue
<template>
  <div id="app">
    <el-tabs v-model="activeName" class="el-tabs-s">
      <el-tab-pane label="输入时改变背景颜色样式" name="a2">
        <el-tag>focus</el-tag>
        <input placeholder="请输入内容" />
        <hr />
        <el-tag>hover</el-tag>
        <span class="span-s">hover</span>
        <el-tag>active</el-tag>
        <button class="button-s">激活样式</button>
      </el-tab-pane>
      <el-tab-pane label="表格奇偶行背景颜色不同" name="a3">
        <el-tag>tr:nth-child(odd)</el-tag><el-tag>tr:nth-child(even)</el-tag>
        <table class="styled-table">
          <tr>
            <!-- 表头行 -->
            <th>id</th>
            <th>姓名</th>
            <th>性别</th>
          </tr>
          <tr>
            <!-- 数据行 -->
            <td>001</td>
            <td>小明</td>
            <td>女</td>
          </tr>
          <tr>
            <!-- 数据行 -->
            <td>002</td>
            <td>小白</td>
            <td>男</td>
          </tr>
          <tr>
            <!-- 数据行 -->
            <td>003</td>
            <td>小红</td>
            <td>男</td>
          </tr>
          <tr>
            <!-- 数据行 -->
            <td>004</td>
            <td>小黑</td>
            <td>男</td>
          </tr>
          <!-- 可以继续添加更多数据行 -->
        </table>
      </el-tab-pane>
    </el-tabs>
  </div>
</template>

2、选择特定位置的元素 ​

伪类选择器可以用来选择处于特定位置的元素，例如第一个子元素、最后一个子元素或者是父元素的唯一子元素。这对于设计复杂的布局和样式非常有用，尤其是在处理列表、表格和导航菜单时。 例如，:first-child、:last-child、:nth-child()等伪类选择器，它们提供了一种灵活的方式来选择和样式化这些特定位置的元素。

vue
<template>
  <div id="app">
    <el-tabs v-model="activeName" class="el-tabs-s">
      <el-tab-pane label="选择特定位置的元素" name="a4">
        <div class="div-child">
          <span>孩子1</span>
          <span>孩子2</span>
          <span>孩子3</span>
          <span>孩子4</span>
          <span>孩子5</span>
        </div>
        <el-divider>代码</el-divider>
        <code-exmaple></code-exmaple>
      </el-tab-pane>
    </el-tabs>
  </div>
</template>
<style scoped lang="scss">
.el-tabs-s {
  width: 100%;
  .div-child {
    span:first-child {
      color: #dd3939;
    }
    span:last-child {
      color: greenyellow;
    }
    span:nth-child(3) {
      background: pink;
    }
  }
}
</style>

3、选择特定属性的元素 ​

虽然属性选择器（如[attribute=value]）可以用来基于元素的属性选择元素，但某些伪类选择器（如:checked）提供了更为简便的方式来选择具有特定属性的元素。例如，:checked伪类选择器可以选择所有选中的复选框和单选按钮，这对于创建自定义表单控件的样式非常有用。

4、增强可访问性 ​

伪类选择器还可以增强网页的可访问性。例如，:focus伪类可以用来为获得焦点的元素定义明显的样式，这对于键盘导航用户来说非常重要。通过提供视觉反馈，用户可以更容易地识别当前交互的元素，从而提高网站的可访问性。

5、无需额外的HTML标记 ​

使用伪类选择器，开发者可以在不增加额外HTML标记的情况下，实现复杂的样式和布局。这有助于保持HTML代码的简洁和语义化，同时还可以减少页面的大小和提高加载速度。

总之，伪类选择器为CSS提供了强大的功能，使得开发者能够以更细致和动态的方式控制网页的样式。它们是现代网页设计中不可或缺的工具，使得网页能够响应用户的交互，同时保持代码的整洁和高效。

二、伪元素选择器 ​

2.1 为啥需要伪元素选择器 ​

伪元素选择器在CSS中的引入，为网页设计和内容表现提供了更加丰富和灵活的手段。伪元素选择器允许开发者访问并样式化一个元素的特定部分，或者在文档树中虚拟地创建新的元素，而这些通常不能通过HTML直接实现。伪元素选择器的存在有几个重要的原因和用途：

1、访问和样式化文档的特定部分 ​

伪元素选择器使得开发者能够访问并样式化元素的特定部分，比如第一行文本、第一个字母、或者元素之前和之后的内容。例如，::first-line 和 ::first-letter 伪元素分别允许开发者为元素的第一行文本和第一个字母设置特定的样式。这在打造具有吸引力的排版和阅读体验时非常有用。

scss
  .letter-s {
    p::first-line {
      color: rebeccapurple;
    }
    // 指定直接子元素
    > p {
      &::first-letter {
        font-size: 28px;
        font-style: italic;
      }
    }
  }

2、在不改变HTML结构的情况下添加内容 ​

通过使用 ::before 和 ::after 伪元素，开发者可以在元素的内容之前或之后插入新的内容或装饰，而不需要修改HTML代码。这种方法非常适合添加图标、装饰性元素或者是为元素添加特殊的前缀或后缀，同时保持HTML的清晰和语义化。

scss
.element-s-b {
    border: 1px solid red;
    background-color: greenyellow;
    // 确保是直接子元素
    > div {
      &::before {
        content: '前缀内容--::before';
        color: blue;
      }
    }
  }

.element-s-a {
    border: 1px solid red;
    background-color: rgba(178, 212, 126, 0.336);
    // 确保是直接子元素
    > div {
      &::after {
        content: '后缀内容--::after';
        color: rgb(209, 104, 19);
      }
    }
  }

3、创建视觉效果 ​

伪元素选择器也常被用于创建特殊的视觉效果，比如自定义的清除浮动方法（使用 ::after 清除浮动），或者是设计复杂的背景装饰和形状。这些都可以通过伪元素以及结合CSS的其他特性（如background、border、box-shadow等）来实现。

scss
.element-s-bfc {
    border: 1px solid red;
    background-color: rgba(64, 191, 241, 0.336);

    > div {
      float: left;
    }
  }
  // 清除浮动样式
  .element-s-c-bfc {
    border: 1px solid rgb(165, 51, 51);
    background-color: rgba(64, 191, 241, 0.336);

    > div {
      float: left;
    }
    // 使用::after来清除浮动
    &::after {
      content: '';
      display: table; // 或者使用 block, 但 table 在某些情况下可能更有效
      clear: both; // 清除左右浮动
    }
  }

4、提高网页性能 ​

使用伪元素可以在不增加额外HTML元素的情况下实现复杂的设计，这有助于减少DOM的大小，从而提高网页的性能。通过减少页面加载时需要解析的HTML标签数量，可以加快页面的渲染速度。

css
.arrow-element {  
  position: relative;  
  padding-left: 20px;  
}  
  
.arrow-element::before {  
  content: '→';  
  position: absolute;  
  left: 0;  
  top: 50%;  
  transform: translateY(-50%);  
}

5、保持HTML的语义化 ​

通过使用伪元素来添加装饰性内容或样式，开发者可以避免在HTML中添加非语义化的标记。这有助于保持HTML文档的清晰和语义化，使得文档的结构更加明确，也更容易被搜索引擎优化（SEO）和屏幕阅读器理解。

总之，伪元素选择器为CSS提供了强大的功能，使得开发者能够以更细致和动态的方式控制网页的样式和内容。它们是现代网页设计中不可或缺的工具，允许开发者在不牺牲HTML语义化的前提下，实现复杂和创新的设计。

三、组合选择器 ​

组合选择器在CSS中确实是非常重要的，它们让开发者能够针对页面中具有特定关系的元素进行更精准、更灵活的样式定制。以下是组合选择器存在和使用的主要原因：

1、元素间关系定位 ​

组合选择器允许开发者根据元素在DOM树中的位置关系来选择元素。例如，子元素选择器（>）可以选择某个元素的直接子元素，相邻兄弟选择器（+）可以选择紧接在另一个元素后的元素，而一般兄弟选择器（~）可以选择同一父元素下的所有后续兄弟元素。

css

/* 选择div的直接p子元素 */  
div > p {  
    color: blue;  
}

/* scss语法 */  
div{
   > p {  
    color: blue;  
   }
}

2、提高选择器的特异性 ​

通过组合多个简单选择器，我们可以创建更具体的选择器，从而提高选择器的特异性。这有助于确保我们的样式规则在应用到页面时具有更高的优先级，特别是在存在多个可能冲突的样式规则时。

3、简化CSS规则 ​

在某些情况下，我们可能希望为一组具有共同父元素或特定关系的元素应用相同的样式。通过使用组合选择器，我们可以将这些元素组合在一起，并为它们编写一个统一的样式规则，从而简化我们的CSS代码。

4、增强代码的可读性和可维护性 ​

通过使用组合选择器，我们可以使CSS代码更加直观和易于理解。当开发者看到一个组合选择器时，他们可以立即理解该选择器所针对的元素以及这些元素之间的关系。此外，由于组合选择器允许我们编写更具体的样式规则，因此我们可以减少样式冲突和覆盖问题的发生，从而提高代码的可维护性。

5、响应式设计和动态布局 ​

在响应式设计和动态布局中，元素的位置和关系可能会随着屏幕尺寸或用户交互而发生变化。通过使用组合选择器，我们可以编写能够自动适应这些变化的样式规则。例如，我们可以使用相邻兄弟选择器来确保当某个元素被添加或删除时，其相邻元素的样式会相应地发生变化。

6、符合文档流和语义化 ​

CSS的许多设计都考虑到了文档流和语义化的概念。通过使用组合选择器，我们可以更好地遵循这些原则，从而创建出既符合文档流又易于理解的样式规则。例如，我们可以使用子元素选择器来选择某个具有特定语义的元素的直接子元素，并为它们应用适当的样式。

总之，组合选择器在CSS中扮演着至关重要的角色，它们提供了一种强大的机制来选择具有特定关系的元素，并允许开发者以更精细、更具体的方式应用样式。通过使用组合选择器，我们可以创建出更灵活、更可维护、更符合语义化的CSS代码。
