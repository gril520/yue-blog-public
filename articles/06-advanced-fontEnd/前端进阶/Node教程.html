Node.js 教程 ​

一、JavaScript 运行时 ​

所谓 JavaScript 运行时（JavaScript runtime）其实就是代码执行环境，最常见的 JavaScript 运行时就是浏览器，但除了浏览器环境，JavaScript 也可以在其他环境下运行。

最初，JavaScript 主要在浏览器中使用，用于增强网页的交互性。但随着时间的推移，出现了如多种服务器端 JavaScript 运行时，使得 JavaScript 能够用于服务器端编程，极大程度扩展了它的应用范围。

二、Node.js 简介 ​

Node 是基于 Chrome V8 引擎的 JavaScript 运行时，由 Ryan Dahl 于2009年发布，通过 Google 的 V8 引擎实现运行 JavaScript，Node 的出现让 JavaScript 不再局限于浏览器，极大扩展了 JavaScript 的应用范围，Node 的一个显著特点是非阻塞的事件驱动架构，适合处理高并发的网络应用。

官方地址：https://nodejs.org，Node 可以用来开发各种应用，例如：

  • 工具类应用（webpack、vite、babel、eslint 等）
  • 服务端应用（网页、App 的各种服务器等）
  • 桌面端应用（VSCode、Figma、Postman 等）

三、下载与安装 ​

**下载地址：**https://nodejs.org/en/download

安装步骤如下：

  • 双击安装文件，依次选择『 下一步 』即可，默认的安装路径是 C:\Program Files\nodejs。
  • 安装完成后，在 CMD 命令行窗口下运行 node -v，如显示版本号则证明安装成功。

我们来尝试把 js 文件在 Node，环境下运行，首先创建文件 hello.js ，内容如下：

**方式二：**使用 vscode 自带的命令行窗口 ，输入『 node hello.js 』即可。

**方式三：**安装插件 『code Runner』, 文件右键 -> 选择 『run code』

注意：在 Node.js 环境下，没有 BOM 和 DOM ，全局对象的名字叫 **global，**没有 window。

四、CommonJS 注意点 ​

本教程中我们主要讲解 CommonJS 模块化，因为 Node.js 遵循的是该模块化标准。

  1. 导入 Node 内置模块时，直接给require传递模块名即可。
  2. 默认情况下导入.js和.json文件时，可以省略文件后缀。
  3. 若require 传递的是文件夹路径，会导入package.json文件中 main 属性指定的文件，若不存在，则会导入文件夹下的 index.js或 index.json，如果依然不存在就会报错。
  4. 每个.js文件都是一个模块，require会引起模块代码执行，执行后决定导出内容。
  5. 模块执行时，是被包裹在一个内置的函数中执行的，所以每个模块都有自己的作用域。

4. 对 Buffer 的理解 ​

Node.js 最初的定位就是服务器端解决方案，所以它需要高效地处理：网络处理、文件操作等等，而这些都涉及到对二进制数据的处理，因此在 Node.js 中引入了一个全局的Buffer类，用于直接操作内存中的二进制数据

六、http 协议 ​

HTTP（hypertext transport protocol），中文名叫 超文本传输协议**，**这个协议详细规定了浏览器和服务器之间互相通信的规则，协议中主要规定了两个方面的内容：

  • 请求报文：客户端向服务器发送的数据。
  • 响应报文**：服务端给客户端返回的数据**。

报文其实可以简单理解为：一些拥有特定格式的字符串。

响应状态码的规律是：

  • 1xx（信息性状态码）这类状态码是信息性的，表示请求已被接收，继续处理中。
  • 2xx（成功状态码）这类状态码表示请求已成功被服务器接收、理解、并接受。
  • 3xx（重定向状态码）这类状态码表示为了完成请求，但请求的资源已被移动，需要进一步操作。
  • 4xx（请求错误状态码）这类状态码表示请求可能出错，妨碍了服务器的处理。
  • 5xx（服务器错误状态码）这类状态码表示服务器在尝试处理请求时发生了错误。

七、IP 地址、域名、端口号 ​

1. IP 地址 ​

IP 地址是网络中每个设备的逻辑标识（数字标识符），定义了设备在网络中的地址。

IP 地址就像城市中一栋大楼的地址，如：北京海淀区上地十街10号。

IP 地址类型

  1. IPv4 地址：

由四组0~255之间的十进制数字组成，用点分隔，例如：220.181.38.150。IPv4 是32位的，即：可以表达的地址总数是 232 个，大约4.29亿个地址。

  1. IPv6 地址：

由八组十六进的制数字组成，用冒号分隔。例如：2001:0db8:85a3:0000:0000:8a2e:0370:7331。IPv6 是128位的，即：可以表达的地址总数是 2128 个，数量及其庞大。

互联网发展迅速，IPv4 地址逐渐不足，因此诞生了128位的IPv6地址，以满足更多设备的需求。

IP 地址分类

  1. 公网地址：可以在公网（整个互联网）上被访问的地址。
  2. 私网地址：仅在局域网内有效，不可直接在互联网上被访问，私网 IP 常见范围是：
  • **10.0.0.0 ~ 10.255.255.255****：**这个范围内的地址被广泛用于大型组织或家庭网络。
  • **172.16.0.0 ~ 172.31.255.255****：**这个范围被用于中型至大型组织。
  • **192.168.0.0 ~ 192.168.255.255****：**这个范围通常被用于小型企业或家庭网络。
  1. 本地回环地址：**127.0.0.1 ~ 127.255.255.254**，用于设备自身通信测试。

例如家庭网络整体结构为：路由器或光猫通常会从运营商获得一个公网IP地址，并为家中的每个设备分配一个私网IP地址（当然部分运营商需要用户申请，才会为用户分配一个公网 IP）。

2. 域名 ​

域名的概念

域名可以理解为给 IP 地址分配一个便于记忆和传播的“别名”，比如要访问百度，可以在浏览器中输入：220.181.38.150，但这个地址不便于记忆和传播，如果使用域名就特别的友好，例如百度的域名是：www.baidu.com。

备注：域名最终也是被转换成了 IP 地址，转换的过程称之为：域名解析。

域名的结构

域名由多个部分组成，通常包括：顶级域名、二级域名、三级域名，或更多级别的子域名，例如在域名 www.baidu.com 中：

  • .com 是顶级域名（TLD），通常表示商业性质的网站。
  • baidu 是二级域名，通常是公司或组织的名称。
  • www 是三级域名，通常用来指代该域名下的一个特定的服务器，如Web服务器。

备注：

  1. 当购买了一个二级域名时，通常你会获得该域名下的所有三级域名的控制权，例如你拥有了baidu.com这个二级域名，你可以创建任意数量的三级域名，如：
    • www.baidu.com
    • wenku.baidu.com
    • tieba.baidu.com
  1. 当然了域名层次也可以通过进一步添加前缀来创建，如：
    • app.api.baidu.com
    • support.api.baidu.com

域名的解析

  1. 查询本地缓存

浏览器首先会检查计算机上的本地缓存，看看是否存储了这个域名的IP地址。如果找到了，浏览器会直接使用这个IP地址，不需要再继续查询。

  1. 联系DNS服务器

如果本地缓存没有结果，浏览器会联系DNS服务器，负责帮你找到域名对应的IP地址。

备注：实际查找过程中需要很多不同层次的 DNS 服务器一起配合，且会读取解析缓存。

3. 端口号 ​

端口号概念端口号是标记计算机中具体应用程序（或进程）的一个数字，IP地址用于找到目的计算机，而端口号则用于找到该计算机上的特定程序，端口号值范围从0 ~ 65535其中0 ~ 1023是系统端口这些端口号被预先定义用于一些常见的网络服务和应用。例如：80端口通常用于http服务，443端口用于 https 服务。

查看端口号按 Win + R 键打开运行对话框。输入 resmon 并按下回车打开资源监视器。转到“网络”选项卡。展开“监听端口”部分以查看哪些端口当前在使用。

4.总结 ​

  1. IP地址：类似于城市中每栋大楼的地址，如：中国北京海淀区上地十街10号。
  2. 域名： IP的别名，域名对记忆和传播更为友好，如：百度总部大厦。
  3. 端口号：用于确定特定房间的编号，如：3002 室。

3. 获取报文 ​

获取请求行

  • 获取请求方式：requestuest.method
  • 获取协议版本：requestuest.httpVersion
  • 获取请求路径：requestuest.url

获取到了请求路径，我们就可以根据不同的路径，返回给浏览器不同的内容，例如：让浏览器呈现内容的同时可以展示页签图标，代码如下：

js
const server = http.createServer((requestuest, response) => {
  // 判断请求路径
  if(requestuest.url === '/favicon.ico'){
    // 读取图标
    let icon = fs.readFileSync('./favicon.ico')
    // 设置图标对应的响应头
    response.setHeader('content-type','image/x-icon');
    // 做出响应
    response.end(icon)
  }else{
    // 设置纯文本对应的响应头
    response.setHeader('content-type','text/plain');
    // 做出响应
    response.end('hello')
  }
})

九、express 框架 ​

1. express 简介 ​

express是一个基于Node.js的轻量级 Web 应用框架，因其简洁性和灵活性而广受欢迎。它提供了一组简单的工具，用于快速创建 Web 应用，官网地址：https://www.expressjs.com.cn

2. 基本使用 ​

第一步：安装 express

npm i express
1

第二步：创建服务

js
//1. 导入 express
const express = require('express');

//2. 创建应用对象
const app = express();

//3. 创建一组响应规则（路由规则）
app.get('/welcome', (request, response) => {
  /*
    注意send方法是express所提供的，而http模块提供的是end方法。
    send方法更好用一些，比如连续调用两次end会报错，send不会。
    send方法还会根据响应的内容，自动设置响应头。
  */
  res.send('hello express');
});

//4. 监听端口 启动服务
app.listen(8088, () =>{
  console.log('服务已经启动, 端口监听为 8088...');
});

3. 路由的使用 ​

一个路由的组成有：请求方法、路径、回调函数，这三部分组成。

express 中提供了一系列方法，可以很方便的使用路由，格式如下：

js
app.请求方法(路径，回调函数)
1

代码示例如下：

js
//导入 express
const express = requestuire('express');

//创建应用对象
const app = express();

//首页路由
app.get('/', (request,response) => {
  response.send('我是主页');
});

//创建 get 路由
app.get('/hot', (request, response) => {
  response.send('我是热门页面');

4. 响应设置 ​

express框架封装了一些API来方便给客户端响应数据，并且兼容原生HTTP模块 API

js
//获取请求的路由规则
app.get("/response", (request, response) => {
  /*
    express也兼容Node内置http模块的api
      response.statusCode = 404;
      response.setHeader('abc','xyz');
      response.end('xxx');
  */

  // express提供的api
  response.status(500); //设置响应状态码
  response.set('token','r5t776tr5e345e'); //设置响应头
  response.send('中文响应不乱码'); //设置响应体
  response.status(404).set('token','r5t776tr5e345e').send('你好啊') //链式调用

  // 其他响应

  response.download('./package.json'); //下载响应
  response.json(); //响应 JSON
  response.sendFile(__dirname + '/home.html') //响应文件内容
});

6. 中间件 ​

  • 中间件（Middleware）本质是一个回调函数。
  • 中间件函数可以像路由回调函数一样，会收到：请求对象、响应对象。
  • 中间件类似于一道道“处理程序”，用于完成一系列任务，如验证、日志记录、数据处理等。

中间件分类

  1. 全局中间件
  2. 路由中间件

1. 全局中间件 ​

每个请求到达服务端之后，都会执行全局中间件，在全局中间件中可以编写额外的处理逻辑。

定义中间件

js
function middle1 (request,response,next){
  //实现功能代码
  //.....
  //执行next函数(当如果希望执行完中间件函数之后，仍然继续执行路由中的回调函数，必须调用next)
  next();
}

十、Ajax（原生） ​

1. Ajax 简介 ​

AJAX 全称为: Asynchronous Javascript And XML，就是异步的 JS 和 XML，通过AJAX可以在浏览器中向服务器发送异步请求，最大的优势：无刷新获取数据。AJAX 不是新的编程语言，而是一种将现有的标准组合在一起使用的新方式。

扩展内容：XML

XML 是可扩展标的记语言，XML 被设计用来传输和存储数据。XML和HTML类似，不同的是HTML中都是预定义标签，而XML中没有预定义标签，全都是自定义标签，用来表示一些数据。

比如一个学生数据可以这存储：

xml
<student>
  <name>张三</name>
  <age>18</age>
  <gender>男</gender>
</student>

5. 跨域问题 ​

5.3. 常见解决方案 ​

1. CORS（Cross-Origin Resource Sharing）

在服务端设置 Access-Control-Allow-Origin 等响应头，来声明允许哪些域进行资源共享

js
/*
  ● Access-Control-Allow-Origin：指定哪些源可以访问资源。可以是具体的一个URL（如http://example.com），或者*表示允许任何源。
  ● Access-Control-Allow-Methods：指定允许的HTTP方法，如GET, POST, DELETE等。
  ● Access-Control-Allow-Headers：指定允许的请求头列表，浏览器会在预检请求中使用此头部告知服务器实际请求中会使用哪些头部。
  ● Access-Control-Allow-Credentials：指示是否允许发送Cookie。如果这个值是true，Access-Control-Allow-Origin就不能设置为*，必须指定明确的、与请求网页一致的域名。
  ● Access-Control-Max-Age：指定预检请求的结果能够被缓存多长时间。
  ● Access-Control-Expose-Headers：指定允许浏览器访问的服务器响应头。默认情况下，只有6个基本响应头是可以读的：Cache-Control、Content-Language、Content-Type、Expires、Last-Modified、Pragma。
*/
response.header('Access-Control-Allow-Origin','*')
response.header('Access-Control-Allow-Methods','*')
response.header('Access-Control-Allow-Headers','*')
